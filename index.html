Personal Project · Open Source

Hybrid retrieval + cross-encoder reranking + agentic query reformulation, over your own documents

Upload documents, ask questions, get answers grounded only in what was actually uploaded - the system says "I don't know" rather than guessing. Dense vector search (pgvector) and lexical search (Postgres full-text) fused via Reciprocal Rank Fusion, reranked with a cross-encoder, with an agentic retry loop - hard iteration cap included, so a genuinely unanswerable question can't loop forever - that reformulates weak queries automatically. Evaluated against a real golden dataset run live against the system, not eyeballed spot checks.

Found and fixed a real retrieval bug along the way: a paraphrased query collapsed retrieval confidence from 0.98 (asking "SonarQube" directly) to 0.0006 (asking "what security tools were used for remediation?"). Traced to a chunk-boundary issue, fixed with embedding-based semantic chunking - then re-diagnosed further when the fix alone turned out not to be sufficient, revealing a second, still-open corpus-imbalance limitation.
